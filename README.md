# PawPath — Web-Based Stray Animal Rescue & Care Management System
**Lab Activity #4: Prompt, Observe, Refine — Effective Prompt Engineering for AI-Assisted Web Development**

## Sector and project concept
**Sector:** Health & Wellness Innovation  
**Challenge (proposed):** Community members may notice stray animals but lack a simple, organized way to record sightings and see sample rescue follow-up status. This is a project premise, not a verified local research finding.  
**Target users:** Community residents, animal rescue volunteers, and shelter coordinators.  
**Core features:** (1) Create a local demo report for a stray animal; (2) filter reports and update demonstration rescue statuses; (3) view basic non-clinical care follow-up examples.

## Scope and safety
- Responsive single-page frontend.
- Semantic HTML, CSS, and vanilla JavaScript.
- Fictional demonstration records only.
- No backend, database, authentication, or external APIs.
- Does not contact rescue teams, provide veterinary diagnosis, or replace professional animal care.
- For real situations, contact the appropriate local animal welfare group or government office. Avoid approaching frightened, injured, or aggressive animals.

## Run
Open `index.html` in a modern browser. No setup or server is required.

## Files
- `index.html` — page structure and sample reports
- `styles.css` — responsive design and focus styling
